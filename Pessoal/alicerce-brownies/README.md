# Alicerce Brownies — Cardápio Digital

Este projeto foi recriado para ficar visualmente bem próximo da imagem de referência enviada.

## Abrir em celular, tablet ou computador

1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` em qualquer navegador moderno, ou use a extensão **Live Server** no VS Code.

O layout é responsivo e funciona offline: não precisa instalar aplicativo nem usar internet para abrir. Em celular, envie a pasta completa ou publique os arquivos em uma hospedagem; nunca envie apenas o `index.html`, pois as imagens também são necessárias.

## WhatsApp

Abra `script.js` e substitua:
`5582999999999`

pelo número real da Alicerce Brownies, sempre no formato:
`55 + DDD + número`, sem espaços, parênteses ou hífen.
