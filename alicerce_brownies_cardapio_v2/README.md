# Alicerce Brownies — Cardápio Digital

Este projeto foi recriado para ficar visualmente bem próximo da imagem de referência enviada.

## Abrir no Visual Studio Code

1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html`.
4. Se quiser, instale a extensão **Live Server** e clique com o botão direito em `index.html` → **Open with Live Server**.

## WhatsApp

Abra `script.js` e substitua:
`5582999999999`

pelo número real da Alicerce Brownies, sempre no formato:
`55 + DDD + número`, sem espaços, parênteses ou hífen.
